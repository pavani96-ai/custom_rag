# Code Style

- Python names use snake_case (functions, variables, modules).
- All functions must have a docstring (Python) or JSDoc comment (JavaScript/TypeScript).
- Maximum line length is 100 characters.
- Use type hints on all Python functions.
- Read config from environment variables through the single settings module.
- Never hardcode secrets, project IDs, or regions.
- Keep logic simple. Split steps into small, named helper functions. No deeply nested code.
  Prefer clear code over clever code.
